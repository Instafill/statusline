# Placeholder, no decision recorded yet

Nothing is decided here. This file exists so that `docs/adr/` is present and
numbered, and so the first real ADR costs a rename and a rewrite rather than a
discussion about where ADRs live and what they look like.

Replace it by renaming the file to `0001-<slug>.md` and writing the decision in
its place. Later ADRs increment from there: `0002-<slug>.md`, and so on.

An ADR is worth writing only when all three hold: the decision is hard to
reverse, a future reader would wonder why it was made, and there were real
alternatives that lost for stated reasons. Anything else is not an ADR.

The template is the whole format:

```md
# Short title of the decision

One to three sentences: the context, what was decided, and why.
```

Add `Status`, `Considered Options` or `Consequences` only when one of them
carries something the paragraph could not.
